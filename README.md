# AWS Student Management System

## Project Overview
Student Management application deployed on AWS EC2.

## Technologies
- AWS EC2
- Linux
- Apache Tomcat 9
- Java
- Git
- GitHub

## Application Features
- Add Students
- View Students
- Update Student Details
- Delete Students

## Deployment
1. Launch EC2 instance.
2. Install Java.
3. Install Apache Tomcat.
4. Deploy student.war.
5. Start Tomcat.
